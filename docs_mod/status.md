## 3. データ移行の考慮事項

* **移行対象**: `s2j_alliance_manager_settings['content_models']`
* **移行先**: CPT `s2j_am_alliance_partner` の各投稿
* **移行タイミング**: プラグインアップデート時、または管理者が `移行を実行` ボタンを押したとき
* **ロールバック**: 移行前に `content_models` をバックアップし、問題発生時に復元可能にする

# Carousel 仕様

## 付録: Carousel 機能の実装詳細

### A.1. 子要素数のカウント方法

* **カウント対象**: 各ランクに属するコンテンツモデル (`frontpage='YES'`) の数
* **カウントタイミング**:
  * 管理画面の表示時: 初期表示時に各ランクの子要素数をカウント
  * コンテンツモデル変更時: コンテンツモデルの追加・削除・変更時に再カウント
  * ランク変更時: コンテンツモデルのランク変更時に再カウント
* **カウント方法**: `contentModels` 配列をフィルタリングし、`rank` が一致し、`frontpage='YES'` のレコード数をカウント

### A.2. Carousel 設定の有効/無効判定

* **有効条件**: 子要素数が4以上8以下
* **無効条件**: 子要素数が4未満または8超過
* **判定タイミング**:
  * 管理画面の表示時: 初期表示時に判定
  * コンテンツモデル変更時: 変更時に再判定
  * 保存時: 保存前に最終判定し、範囲外の場合は `carousel_enabled=false` に強制設定

### A.3. フロントエンド Carousel 表示の実装

* **表示条件**:
  * `carousel_enabled=true` かつ
  * 子要素数が4以上8以下
* **表示方法**:
  * 自動スライド機能 (JavaScript による制御、3秒ごとに自動スライド) (✅実装済み)
  * ホバー時のアニメーション一時停止 (✅実装済み)
  * スライド・ナビゲーション (「◀」「▶」) を表示 (✅実装済み)
  * インジケータ (ドット) を表示 (✅実装済み)
  * タッチスワイプ対応 (モバイル環境、最小スワイプ距離50px) (✅実装済み)
  * 無限ループ対応 (2番目のセットを使用したシームレスなループ) (✅実装済み)
* **フォールバック**: 条件を満たさない場合、通常のグリッド表示にフォールバック (✅実装済み)

### A.4. バリデーションルール

* **管理画面でのバリデーション**:
  * 子要素数が4未満または8超過の場合、チェックボックスを無効化
  * 無効化時の理由をヘルプテキストで表示
* **保存時のバリデーション**:
  * 子要素数が4未満または8超過の場合、`carousel_enabled` を `false` に強制設定
  * バリデーションエラーをログに記録 (デバッグ用)
